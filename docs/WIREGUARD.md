# WireGuard Setup Guide

## Topology: Hub and Spoke

```
                    rammstein (Hub)
                    10.66.0.1
                    Public: 51820/udp
                         │
          ┌──────────────┼──────────────┐
          │              │              │
   greenday (spoke)  daftpunk (spoke)  sophon (spoke)
     10.66.0.2       10.66.0.3       10.66.0.5
          │              │              │
          └──────────────┴──────────────┘
                    yoga (spoke)
                    10.66.0.4
```

All spoke nodes connect to the hub. The hub routes traffic between peers. This means:
- greenday can reach daftpunk (traffic goes: greenday -> hub -> daftpunk)
- sophon can reach yoga (traffic goes: sophon -> hub -> yoga)
- The hub must have IP forwarding enabled (handled by the wireguard role)

## Key Generation

```bash
# Generate keys for each host:
./scripts/generate-wg-keys.sh

# This creates wg-keys/ with private/public keypairs and a YAML snippet
# to paste into inventory/group_vars/all/vault.yml
```

## Configuration

All WireGuard config is generated by Ansible from templates. The template at `roles/wireguard/templates/wg0.conf.j2` produces:

### Hub (rammstein):
```ini
[Interface]
PrivateKey = <hub-private-key>
Address = 10.66.0.1/16
ListenPort = 51820
MTU = 1420

# Peer: greenday
[Peer]
PublicKey = <greenday-public>
AllowedIPs = 10.66.0.2/32
Endpoint = 0b.ar:51820
PersistentKeepalive = 25

# ... (all wg_peers listed)
```

### Spoke (e.g., greenday):
```ini
[Interface]
PrivateKey = <greenday-private>
Address = 10.66.0.2/16
MTU = 1420

# Peer: rammstein (hub)
[Peer]
PublicKey = <hub-public>
Endpoint = randazzo.ar:51820
AllowedIPs = 10.66.0.0/16  # All WG traffic goes through hub
PersistentKeepalive = 25
```

Note: `ListenPort` is only set on the hub. Spokes initiate connections and don't need to listen.

## Inventory Groups

WireGuard uses two inventory groups:
- `wg_hub` -- single host (rammstein). The hub routes between all peers.
- `wg_peers` -- all hosts participating in the mesh. Add a host to this group to include it in WireGuard.

## Management Commands

```bash
# Check status on any host:
wg show

# Restart WireGuard:
systemctl restart wg-quick@wg0

# Re-mesh (update all peers):
ansible-playbook playbooks/wireguard.yml --ask-vault-pass

# Check handshake status:
wg show wg0 latest-handshakes

# Check transfer stats:
wg show wg0 transfer

# Troubleshoot:
journalctl -u wg-quick@wg0 -f
```

## Adding a New Peer

1. Generate keys: `wg genkey | tee /tmp/new.key | wg pubkey > /tmp/new.pub`
2. Add to vault:
   ```bash
   ansible-vault edit inventory/group_vars/all/vault.yml
   # Add to wg_private_keys and wg_public_keys
   ```
3. Add host to `inventory/hosts.yml` in the `wg_peers` group with `wg_ip: 10.66.0.6`
4. Create `inventory/host_vars/<new-host>.yml` with `wg_ip` and `ansible_user`
5. Add to `~/.ssh/config`
6. Re-run: `ansible-playbook playbooks/wireguard.yml --ask-vault-pass`
